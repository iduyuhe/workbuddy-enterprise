description: 把研报/营销/对客材料的表述与内部合规制度、监管红线逐条比对，标注风险等级与修改建议。
---
# 适用场景
合规岗需对研报、产品说明书、营销话术、对客沟通材料做合规审查，确保不触碰监管与内部红线。

# 执行步骤
1. 取材料：读取待审文本（段落级拆分）。
2. 检索制度：在合规知识库检索「内部合规制度」与「监管法规摘要」中的适用条款与禁止用语清单。
3. 比对：逐段与条款做语义比对，标记命中的禁止项/限制项/需披露项。
4. 分级：风险等级 = 红线（禁止）/ 限用（需改述）/ 提示（建议补充披露）。
5. 输出：合规结论表 = 段落 + 命中条款 + 风险等级 + 修改建议；同步写入审计留痕。

# 输出格式（建议）
```
| 段落 | 命中条款 | 等级 | 建议 |
| "本产品收益稳定" | 营销禁语-收益承诺 | 红线 | 改为「历史区间收益，非承诺」 |
| "行业第一" | 广告法-绝对化用语 | 限用 | 改为「位居前列」，附依据 |
```

# 注意事项
- 仅做比对与建议，最终放行由合规官在系统中确认（不自动通过）。
- 所有比对过程须可回溯（命中条款原文 + 时间戳），满足审计要求。
