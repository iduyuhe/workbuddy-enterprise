# 适用场景
研究员上传研报草稿、会议纪要、财报/行业数据素材，需要快速生成摘要或对关键口径提问。

# 执行步骤
1. 解析输入：识别文档类型（宏观/行业/公司/策略）与核心标的。
2. 摘要：在合规知识库检索相关监管与制度约束后，产出执行摘要（核心观点/风险/评级）。
3. 抽取：抽取关键数据（EPS、目标价、行业增速等）并标注来源与统计口径。
4. 问答：基于全文回答研究员追问（如「与目标价相比上行空间？」「主要下行风险？」）。
5. 提示：对可能触碰合规红线的表述给出预警（转交「合规条款比对」技能）。

# 输出格式（建议）
```
【执行摘要】行业景气回升，给予「增持」评级，目标价 X，上行空间 Y%。
【关键数据】EPS 预期 A（口径：一致预期）/ 行业增速 B（来源：协会披露）
【合规提示】「稳赚」「无风险」类表述命中红线，建议修改为「历史回测表现」。
```

# 注意事项
- 不杜撰数据；缺失口径须显式标注「待研究员核实」。
- 任何收益/评级表述须可回溯到素材与制度，禁止绝对化承诺用语。
