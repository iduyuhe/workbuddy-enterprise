---
name: 监管报送核对
description: 经报送系统连接器核对监管报表字段口径、提示缺失项与差错，降低报送受罚风险。
---
# 适用场景
合规/报送岗在提交 EAST / 1104 / 反洗钱 / 风险加权资产等监管报表前做自动核对。

# 执行步骤
1. 取报表：调用 `call_mcp_tool` 经报送连接器拉取待报送报表与元数据（字段/口径/报送期）。
2. 取义务：查询报送义务日历，确认本期应报报表清单与截止日，标记缺失报表。
3. 口径核对：逐项比对字段口径与监管定义（如「不良贷款」认定标准），标记偏离与缺值。
4. 交叉校验：做表内/表间勾稽（如资产=负债+权益），标记不平衡项。
5. 输出：报送校验报告 = 缺失报表 + 字段差错 + 勾稽异常 + 修改建议；生成报送草稿（需复核后提交）。

# 输出格式（建议）
```
【缺失】本期应报 12 张，已备 11 张，缺《G12 流动性）》—— 截止前需补
【差错】EAST_贷款.利率 3 笔为空，监管口径须非空
【勾稽】表内资产≠负债+权益（差 0.4 亿）—— 疑似漏报科目
```

# 注意事项
- 仅生成草稿与校验报告，真正报送由合规官在报送系统确认提交。
- 涉及客户敏感字段须遵循最小化与脱敏原则（平台内容审核 + 审计留痕）。
