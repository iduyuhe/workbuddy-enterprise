---
# 适用场景
工艺/质量工程师希望系统性提升一次交检合格率（FPY），而非凭经验试错。

# 执行步骤
1. 取数：调用 `call_mcp_tool` 经 MES 连接器拉取近 M 个批次的工艺参数（炉温/压力/转速/节拍）与良率。
2. 关联：在知识库检索「工艺标准」中的参数规格带，标记超差批次。
3. 归因：做参数-良率的相关性/贡献度排序，定位 Top-3 敏感参数。
4. 建议：给出每个敏感参数的「推荐区间」（在规格带内偏向良率最优侧）与试探步长。
5. 输出：参数调整建议表 + 预期 FPY 收益区间 + 需 DOE 验证的提示。

# 输出格式（建议）
```
| 参数 | 当前 | 规格带 | 推荐区间 | 预期影响 |
| 回流焊峰值温 | 245℃ | 240–250 | 246–248 | FPY +1.5~2.5pt |
| 印刷压力 | 4.5kg | 3.5–5.0 | 4.0–4.5 | FPY +0.8~1.2pt |
```

# 注意事项
- 建议区间须落在「工艺标准」规格带内；超出须标注「需工艺评审」。
- 推荐先做小批 DOE 验证再全线推广。
