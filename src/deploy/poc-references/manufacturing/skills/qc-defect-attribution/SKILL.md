---
name: 质检缺陷归因
description: 根据缺陷现象（代码/产线/批次/图片描述），在知识库检索相似案例并生成 Top-3 根因假设与整改建议。
---
# 适用场景
质检员或班组长上报缺陷：给出缺陷代码、产线、批次、现象描述（可附图片描述）。

# 执行步骤
1. 解析输入：提取 `defect_code`（缺陷代码）、`line`（产线）、`batch`（批次）、`symptom`（现象）。
2. 检索：调用 `search_kb`（默认 qc-kb）按缺陷代码 + 现象关键词检索相似历史缺陷与标准条款。
3. 归因：比对「缺陷代码库」与「工艺标准」，结合本次批次的工艺参数，生成 Top-3 根因假设（含置信度）。
4. 印证：调用 `call_mcp_tool` 回查 MES 该批次的工艺参数曲线与设备状态，确认/排除假设。
5. 输出：归因报告 = 根因假设 + 置信度 + 整改建议 + 是否建议沉淀为新案例。

# 输出格式（建议）
```
- 根因假设 1（置信度 82%）：焊温偏低导致虚焊 —— 建议复测炉温曲线
- 根因假设 2（置信度 61%）：来料批次波动 —— 建议追溯来料检验
- 整改建议：@设备工程部 复校回流焊炉温；@质量部 加严来料 IQC
- 是否沉淀：是（命中历史案例不足，建议新增）
```

# 注意事项
- 仅给建议，不自动下发工艺变更指令（安全件须人工确认）。
- 涉及人身/安全的关键缺陷必须显式标注「需工程师复核」。
