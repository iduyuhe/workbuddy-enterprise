---
name: 预测性维护
description: 基于设备传感器遥测时序数据，识别劣化趋势并在非计划停机前主动告警，给出维护窗口建议。
---
# 适用场景
设备工程部希望对关键设备（贴片机、回流焊、CNC、注塑机）做预测性维护，减少突发停机。

# 执行步骤
1. 取数：调用 `call_mcp_tool` 经 MES 连接器拉取目标设备近 N 天传感器遥测（温度/振动/电流/节拍）。
2. 特征：计算趋势斜率、方差、与基线阈值的偏离度；识别异常窗口。
3. 研判：结合「设备运维手册」中的告警阈值与典型失效模式，判定劣化等级（观察/预警/紧急）。
4. 建议：给出建议维护窗口（避开排产高峰）与首选排查项。
5. 回写：经 MES 连接器创建维护工单草稿（不自动执行停机）。

# 输出格式（建议）
```
- 设备 CNC-07：主轴振动 RMS 周增幅 +18%，达到「预警」级
- 预计剩余可用：~9 天（置信区间 6–14 天）
- 建议窗口：本周六 20:00–22:00 停机复校；首选排查：轴承润滑 + 动平衡
```

# 注意事项
- 仅生成工单草稿，真正停机排程由设备工程部在 MES 确认。
- 遥测缺失超过 30% 时降级为「数据不足，建议人工点检」。
