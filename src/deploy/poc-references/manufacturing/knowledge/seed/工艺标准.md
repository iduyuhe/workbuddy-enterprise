# 工艺标准（种子）

> 工艺参数优化技能引用的规格带。真实项目替换为客户的受控工艺文件（如 PFMEA / 控制计划）。

## SMT 回流焊曲线
- 预热区：150–180℃，60–90s。
- 恒温区：180–200℃，60–120s。
- 峰值温：240–250℃（无铅），驻留 10–30s。
- 升温速率：< 3℃/s。

## 印刷工序
- 刮刀压力：3.5–5.0 kg。
- 印刷速度：20–60 mm/s。
- 钢网厚度：0.10–0.15 mm（按器件间距）。

## CNC 切削
- 主轴转速：按刀具直径与材料查表（示例：铝件 Ø10 立铣 6000–9000 rpm）。
- 进给：0.05–0.12 mm/齿。
- 切深：粗加工 ≤ 1.5×刀具直径，精加工 ≤ 0.3 mm。

## 良率口径
- 一次交检合格率 FPY = 一次通过检验数 / 总送检数（不含返修后复检）。
- 目标：SMT 段 FPY ≥ 96%；机加段 FPY ≥ 98%。
