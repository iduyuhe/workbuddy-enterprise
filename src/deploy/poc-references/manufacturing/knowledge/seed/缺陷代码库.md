# 缺陷代码库（种子）

> 质检知识库种子文档之一。首次铺包时由 provision.py 灌入 qc-kb。
> 真实项目应替换为客户自身的缺陷代码体系（如 IPC-610 类别 / 企业自定义码）。

## 常见 SMT 缺陷代码

| 代码 | 名称 | 典型根因 | 关联工序 |
|---|---|---|---|
| D01 | 虚焊 | 焊温偏低 / 焊膏量不足 | 回流焊 |
| D02 | 桥连 | 焊膏过厚 / 钢网开口偏大 | 印刷 + 回流 |
| D03 | 偏移 | 贴装精度漂移 / 基板翘曲 | 贴片 |
| D04 |  tombstone（立碑） | 两端受热不均 / 焊盘不对称 | 回流焊 |
| D05 | 少锡 | 钢网堵塞 / 刮刀压力不足 | 印刷 |

## 常见 CNC/机加缺陷

| 代码 | 名称 | 典型根因 | 关联设备 |
|---|---|---|---|
| M01 | 尺寸超差 | 刀具磨损 / 热变形 | CNC |
| M02 | 表面振纹 | 主轴轴承劣化 / 切削参数不当 | CNC |
| M03 | 毛刺 | 刀具钝化 / 进给过快 | CNC |

## 使用说明
- 缺陷归因技能会按 `代码 + 现象` 检索本表，匹配典型根因作为假设起点。
- 新归因结论经人工确认后，应沉淀为新的「案例」条目（建议字段：代码/产线/批次/根因/措施/效果）。
