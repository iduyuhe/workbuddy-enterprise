# 商业化支撑文档（阶段 5 · 块 B）

面向「首份付费合同（2026.11 里程碑）」与规模销售的商业化支撑材料。本文是销售、售前、交付、法务协同的统一底稿，与 `ROADMAP.md` 阶段 5、`PILOT_DELIVERY.md`、`WorkBuddy-企业级本地化部署平台-评估与规划报告-v1.0.md` 配套。

> ⚠️ 本文定价/测算为**对外报价框架与保守测算口径**，最终以合同为准；所有数字均来自规划报告，非承诺值。

---

## 1. 价值主张与三道护城河

WorkBuddy Enterprise 不拼通用大模型能力，定位为 **「面向 B 端、数据不出域、可治理的私有化 AI 智能体平台」**。差异化建立在三道护城河上（见规划报告 4.2）：

| 护城河 | 具体表现 | 客户可感知价值 |
|---|---|---|
| **极致消费级体验** | 沿用 WorkBuddy 个人版交互沉淀 | 员工上手零培训， adoption 高 |
| **行业场景深度** | 制造 / 金融 / 能源 / 政务，每行业 3-5 个 Killer Scenario | 不是「通用聊天」，是「岗位生产力」 |
| **企业级治理底座** | 私有化 + 审计 + 等保三级（规划）+ 信创（规划）+ 内容审核 | 过得了安全审计，进得了内网 |

**一句话定位**：把企业自己的「技能 / 岗位 / 专家 / 团队」沉淀为可治理、可复用的智能体资产，且数据全程不出公司内网。

---

## 2. 目标客群与分层

优先吃下「中型企业 + 行业场景」长尾市场，不与巨头拼资源（规划报告风险应对）。

| 层级 | 客群 | 切入点 | 适配版本 |
|---|---|---|---|
| L1 标杆大客户 | 央企 / 大型金融 / 能源集团 | 行业 Killer Scenario POC → 私有化旗舰版 | 本地化旗舰版 |
| L2 行业头部 | 制造 / 金融 / 能源头部民企 | 单场景试点 → 行业定制版 | 行业定制版 |
| L3 中型客户 | 产业园区 / 专精特新 / 政务下属单位 | SaaS 订阅快速上线 | SaaS 订阅版 |
| L4 生态伙伴 | ISV / 系统集成商 | 集成分成，复用市场 | 生态版 |

> 早期策略（规划报告 4.1）：先用 SaaS 化 + POC 快迭代建立样板，先打长三角制造业、政府产业园；销售周期长（央企/金融决策 6-12 个月），以 POC 缩短首单路径。

## 3. 定价与授权模型（对外报价框架）

报价四档，与规划报告 2.5.2 一致：

| 版本 | 定位 | 定价口径 | 授权方式 |
|---|---|---|---|
| **本地化旗舰版** | 大型国企 / 央企 / 政府 | **¥80-150 万/年**（含 50 席位，一次性部署 + 年费维保） | 私有化部署授权 + 年维保 |
| **行业定制版** | 金融 / 制造 / 能源头部 | **¥50-100 万/年** | 私有化部署 + 行业场景定制 |
| **SaaS 订阅版** | 中型企业 | **¥800-3000 /席/月**（按用量阶梯） | 多租户 SaaS 订阅 |
| **生态版** | ISV 集成 | 项目分成模式 | 集成授权 + 收入分成 |

### 3.1 计费维度说明

- **席位（Seat）**：激活用户数，旗舰版含 50 席、超席按阶梯加价。
- **租户（Tenant）**：多租户隔离单元，集团型客户按子公司/部门拆租户不加价。
- **节点（Node）**：推理/向量/网关的计算节点，按部署规模计入年维保。
- **定制场景（Scenario）**：行业 Killer Scenario 按套计费，复用 `poc-references/` 骨架可大幅降本。
- **GPU 推理资源**：默认客户自备机房/IDC；亦可由我方代采最小推理集群（1×8 H20 + 1×4 L40，见规划报告 4.1）。

### 3.2 授权与交付组合

| 组合 | 适用 | 说明 |
|---|---|---|
| 永久授权 + 年维保（15-20%） | 央企/金融 | 资产归属客户，年费覆盖升级/补丁/支持 |
| 纯订阅（年付/月付） | 中型/SaaS | 低门槛，按需扩缩 |
| POC 转商用（抵扣） | 所有 | POC 阶段费用按比例抵扣首年合同（参考赫兹归心 Node 8/9 + 合同法第 15 条冲抵模式） |

## 4. 竞品定位

| 竞品 | 强项 | 我们的差异化 |
|---|---|---|
| OpenAI / ChatGPT Enterprise | 最强模型生态 + Azure 政企通道 | 不拼通用能力；用模型网关兼容 Claude/Codex 作加分项，私有化脏活累活是其不愿做 |
| 字节扣子 Coze | 开源私有化、门槛低 | 我们重**行业深度 + 治理底座**（审计/等保/信创规划），而非通用搭建 |
| 阿里百炼 | 央企案例单价 100-500 万/年 | 中小客户 + 行业长尾市场，极致体验 + 更快 POC |
| 百度千帆 | 混合云/边缘、等保 2.0 | 等保三级 + 信创路线（规划），数据不出域更彻底 |
| 腾讯 / 字节 | 资源碾压 | 不拼资源拼行业深度，吃长尾 |

> 标杆参照：阿里百炼央企客户案例单价 100-500 万/年；Claude Enterprise 起价 20 席、超大客户定制价更高（规划报告 2.5.2 注）。

## 5. ROI 与价值量化（保守测算）

来自规划报告 2.5.3：

| 客户类型 | 数量 | 单价 | 年收入 |
|---|---|---|---|
| 标杆大客户（央企/金融） | 5 | ¥100 万 | ¥500 万 |
| 行业中型客户 | 20 | ¥30 万 | ¥600 万 |
| SaaS 订阅（500 席） | — | ¥1.5 万/席/年 | ¥750 万 |
| **18 个月累计** | | | **约 ¥1850 万** |
| **3 年规模化** | 100+ 客户 | — | **¥5000 万-1 亿** |

**ROI 杠杆（向客户讲清）**：
- 岗位场景替代重复脑力劳动（知识检索/报告生成/合规审查）→ 人力工时节省。
- 知识资产复用（Skills/MCP/剧本）→ 一次沉淀、全员复用，边际成本趋零。
- 数据不出域 → 规避合规罚款与数据泄露风险成本。

**常见问题（FAQ）速答**：
- *数据会出域吗？* 不会。推理、向量、业务元数据全部运行在客户内网；支持私有化大模型。
- *用哪家大模型？* 模型网关抽象，兼容 Claude/Codex/Qwen3/DeepSeek，客户自带 Key 或私有化权重。
- *过不了安全审计怎么办？* 已内置审计日志、内容审核、RBAC、OIDC；等保三级与信创路线已在规划。
- *部署周期？* POC 可天级铺包（见 PILOT_DELIVERY）；生产化走 K8s + Helm 编排。
