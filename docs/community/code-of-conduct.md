# 行为准则

本页为仓库根 [`CODE_OF_CONDUCT.md`](https://github.com/iduyuhe/workbuddy-enterprise/blob/main/CODE_OF_CONDUCT.md) 的站点镜像，内容以根文件为权威来源。

## 我们的承诺

为了营造开放、友好的社区环境，我们作为维护者与贡献者承诺：让每个人都能在不受骚扰的前提下参与项目，无论年龄、体型、可见或不可见残障、族群、性别、性取向、经验水平、教育背景、社会经济地位、国籍、外貌、宗教或身份认同。

## 我们的准则

**值得鼓励的行为：** 使用友好、包容的语言；尊重不同的观点与经验；优雅地接受建设性批评；以社区整体利益为重；对其他社区成员保持同理心。

**不可接受的行为：** 色情语言或图像、任何形式的骚扰；挑衅、侮辱性 / 贬低性评论、人身或政治攻击；公开或私下的 harassment；未经明确许可公开他人私人信息；其他在专业场合中合理认定为不当的行为。

## 执行与举报

本准则适用于所有项目空间（代码仓库、Issue、PR、Discussion、官方社群）。遭遇不当行为，请通过 GitHub 私下联系维护者（Security Advisory 或私信），所有举报将被认真、迅速、保密地处理。维护者负责采取适当且公平的纠正措施，并须对处理过程保密。
