# 路线图

完整条目见仓库根 [`ROADMAP.md`](https://github.com/iduyuhe/workbuddy-enterprise/blob/main/ROADMAP.md)。本页为社区视角摘要。

## 已完成阶段

- **阶段 1（v0.1.0）**：MVP 最小闭环 —— 私有化底座 + 7 微服务 + 前端 + RAG 全链路验证。
- **阶段 2**：生产数据层（PostgreSQL / Qdrant）、内容审核、Agent 运行时、Skills / MCP 真实执行。
- **阶段 3**：信创适配（鲲鹏 / 海光 / 麒麟 / 达梦）、等保三级、密评、多租户。
- **阶段 4（收尾中）**：
  - ① 千企规模 K8s + Helm 交付 ✅
  - ② 生态市场（技能 / 连接器 / 专家包交易）✅
  - ③ 标杆 POC（制造业 / 金融业 Killer Scenario 参考骨架）✅
  - ④ 社区运营（本文档站、示例库、贡献者激励）✅

## 社区可参与的下一步

- **示例库扩充**：欢迎提交更多行业 / 场景的 `examples/`（见 [示例库](examples.md)）。
- **市场包共建**：把团队沉淀的技能 / 连接器打包上架生态市场。
- **文档本地化与补全**：`docs/` 任何页面的修正、翻译、补充。
- **路线图提案**：L1+ 贡献者可在 Discussions 提交并投票下一阶段方向。

> 路线图变更遵循[治理文档](governance.md)的「懒惰共识」原则，重大变更需 ≥ 2 名 Maintainer +1。
