# Hello Skill

## 何时使用
用户发起寒暄、首次进入对话、或询问"你能做什么"。

## 步骤
1. 用 1 句话回礼，带上产品名 WorkBuddy Enterprise。
2. 用 ≤ 3 个要点说明平台能做什么（私有化部署 / 知识库 RAG / 技能与连接器）。
3. 引导用户说出具体场景（如"我想接入我们公司的知识库"）。

## 注意事项
- 不编造功能，不确定时引导到人工或文档。
- 保持简洁，单次回复不超过 3 个要点。
- 涉及敏感数据时提示用户走授权流程，不在此技能内处理。
